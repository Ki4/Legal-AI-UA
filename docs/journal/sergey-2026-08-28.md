# 2026-08-28 — ADM-3, first pass: the argument that was wrong twice

Branch `sergey/core-contract-adr`, commit `9d61db7`, pushed without a PR.

## What was tried

Two decisions were reached alone, written down, and then sent to an adversarial review before any
code. Both came back broken, and both breakages were verified by hand against the repository rather
than taken on the reviewer's word.

**OpenAPI as the contract artifact.** The reasoning was that plain JSON Schema leaves the HTTP
envelope living only in TypeScript, which ADR-0016 forbids. True, and still not enough: ajv runs
default-strict on plain JSON Schema and needs `strict: false` against an OpenAPI document — and
`strict: false` disables the check for a misspelled `additionalProperies`, the keyword every drift
argument here rests on. FastAPI also produces OpenAPI rather than consuming it. Abandoned for plain
JSON Schema plus a small `operations.json` that a test actually checks.

**Structured law references as `{source, act_id, article}`.** Justified by "§9 must answer which
services depend on this article". That justification was false and one `ls supabase/migrations`
would have shown it: `law_norms` has existed since 2026-08-15 and `service_law_refs` already answers
exactly that. Worse, the triple cannot express act-scope, which §9.4 permits and the migration
enforces. Replaced by pointer-plus-snapshot, and deferred to the pass that freezes the field list.

## What was learned

**The drift argument that convinces is not the one that holds.** `additionalProperties: false` plus
full `required` plus no optional properties does pin the key set — and says nothing about values. A
schema enum of two against a union of three, with every fixture using the first, passes both sides;
the failure lands later as `undefined` out of a `Record` lookup. The fix was already in the
repository: the `AUDITED_TABLES` pattern in `packages/db`.

**A gate can be half-inert without looking it.** Of the four drift cases, three go red under
`pnpm test` and the fourth — a property added to the interface alone — only under `pnpm typecheck`,
because Vitest transpiles types away without checking them. Running the test suite, seeing green,
and concluding the bridge was complete was available and wrong. This is the session's transferable
lesson and it belongs to no PR: **verify a gate by watching it fail, and check which command it
fails in.**

## What was not done

No PR opened. The remaining four passes each branch from `main` after the previous merges, because
stacking is forbidden and the 2026-08-11 attempt closed a dependent PR unmerged.
