# 2026-09-17 — a session that came back cold, and two tools that acted on a preview

Three PRs document what changed. These are about how the work went, so they have no PR to live in.

## Re-entering a project is a document, not a conversation

The session began with "I have honestly forgotten the project". The answer was not the briefing —
STATE is written for a session that remembers — but a walk from VISION down: what it is, the fifteen
principles and which failure paid for each, what exists by layer, what each debt means in a sentence.
It was saved outside the repository, on the product owner's desktop, because it is a re-entry aid and
not a repository artifact; the repository already says all of it, spread across forty documents. The
tiering serves a session that remembers. A person who does not needs a fourth tier, written for them
once, and it took the rest of the reading budget to produce.

## Two tools acted on a preview

`supabase config push`, run to see a diff, applied it: with stdin not a TTY the prompt is skipped.
`gh pr merge --auto` on a repository with no required checks merges immediately. Both were "look
before acting" calls that acted. Neither is a bug in the tool; both are a wrong model of what
"preview" means to the tool. The rule that follows is cheap and was not being applied: a command
whose name is a verb is assumed to do the verb, and the preview is `--help`, a dry-run flag, or
nothing. The first cost the product owner four dashboard screens to undo; the second cost nothing,
which is luck rather than design — `main` has no required checks, and should.

## The classifier is a reviewer with no context

Auto mode refused `config push` from a temporary directory and a credential-store read — the revert
of the very change it had allowed minutes earlier. Right call both times, read cold: a push from
outside the repository and a read of the keyring look like exfiltration. The cost was that the
revert became dashboard clicks and screenshots. What is worth keeping is the order: after two
refusals, stop and hand the person the clicks, rather than trying a third phrasing.

## A fine-grained token is not a smaller legacy token

Three tokens were generated to make `cloud-ledger` green: read-only, then with Database JIT write,
then the question whether to keep going. The permission behind the login-role endpoint is not named
where a person can find it, and each try cost the product owner a form and a secret update. The
stopping rule was stated by them, not by me — no real data, no real services, park it and write down
how to un-park it — and it was the right call three tokens earlier. A gate whose fix is a guessing
game is parked with a date, not chased.

## A hand-maintained list had stopped a month ago

The access-control table in `docs/CONTRIBUTING.md` — the substitute for the second reviewer — ended
at 2026-08-15. Five migrations with policies and grants had landed since, none listed. Nothing
holds the table to `supabase/migrations/`, and the sentence beneath it still said "thirteen".
Found while adding the fourteenth, fixed by adding all six, and recorded in the sentence itself
rather than in STATE: a list that says when it last stopped is more honest than one that looks
complete.
