# 2026-09-18b — an unattended hour

**Asked:** what can be done in an hour with nobody at the keyboard and no cloud access.

**Done:** four debts from STATE, four PRs, all merged the same evening (#80–#83). The selection
rule was the whole trick: everything that needed the cloud — a secret, a deploy, a sign-in, a
`migration repair` — was excluded up front, and everything left was local and self-verifying. A
test that can be shown to fail (`git stash` the fixture, break the line, run the probe) needs
nobody to look at a screen.

**Learned:**

- The route walk passed 60 of 68 on its first run, and all eight failures were the test's, not the
  screens': `/login` and `/register` sit outside the shell and have no `<main>`. That is the right
  first run for a test meant to fail — it failed, and the failure was legible enough to fix in one
  edit. A first run of 68/68 would have been the one to distrust.
- Three PRs each appended a probe to the end of `PROBES`, and would have conflicted pairwise on
  merge. Caught by a dry-run merge of all three on a scratch branch, fixed by moving each probe
  beside its kin. Now a rule in the root `CLAUDE.md`.
- `pnpm probes` refuses a dirty tree, by design. The order is commit → probe → push; running it
  before the commit costs a turn.

**Abandoned:** the fourth task was first declared out of reach — seven of eight console APIs are
live Supabase, and swapping them looked like an hour on its own. It was twenty-five minutes, because
every feature already had a `*.mock.ts` typed to the same contract: the seam the DoD insisted on for
other reasons is exactly the seam a walk needs. The estimate was wrong in the direction estimates
about well-shaped code usually are.
